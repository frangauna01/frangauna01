| Proyecto | Descripción | Stack | Rol / Aporte |
|----------|-------------|-------|--------------|
| PsyMatch | Plataforma que conecta pacientes con profesionales de salud mental mediante recomendaciones personalizadas, filtros avanzados y agendamiento con pago online. | TypeScript, NestJS, Express, TypeORM, PostgreSQL, MongoDB, React, Tailwind | Desarrollo fullstack con foco en backend: modelado de datos, endpoints REST, lógica de emparejamiento (matching), optimización de consultas y soporte a integración frontend. |
